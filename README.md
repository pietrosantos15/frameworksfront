## 📋 Atividades Propostas



#### Atividade 01 — Campo Minado 

**Descrição:** Desenvolver um pequeno jogo interativo utilizando linguagens fundamentais da Web, como HTML5 e canvas ou display via Vercel.

**Tecnologias:** HTML5 / CSS / JavaScript

🔗 **Links da Atividade:**
- [Repositório GitHub](https://github.com/pietrosantos15/todolist)
- [Deploy Vercel](https://todolist-delta-navy.vercel.app/)

#### Atividade 02 — Campo Minado em React 

**Descrição:** Criação de uma aplicação de teste de digitação utilizando React, inicialização de repositório Git, publicação no GitHub e deploy com GitHub Pages ou Vercel, com resumo sobre o passo a passo, comparação e registro no README.

**Tecnologias:** React / JavaScript / Vercel

🔗 **Links da Atividade:**
- [Repositório GitHub](https://github.com/pietrosantos15/projeto)
