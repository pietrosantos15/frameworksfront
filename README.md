## 📋 Atividades Propostas



#### Atividade 01 — Campo Minado 

**Descrição:** Desenvolver um pequeno jogo interativo utilizando linguagens fundamentais da Web, como HTML5 e canvas ou display via Vercel.

**Tecnologias:** HTML5 / CSS / JavaScript

🔗 **Links da Atividade:**
- [Repositório GitHub](https://github.com/pietrosantos15/todolist)
- [Deploy Vercel](https://todolist-delta-navy.vercel.app/)

---

#### Atividade 02 — Campo Minado em React 

**Descrição:** Criação de uma aplicação de teste de digitação utilizando React, inicialização de repositório Git, publicação no GitHub e deploy com GitHub Pages ou Vercel, com resumo sobre o passo a passo, comparação e registro no README.

**Tecnologias:** React / JavaScript / Vercel

🔗 **Links da Atividade:**
- [Repositório GitHub](https://github.com/pietrosantos15/projeto)
- [Deploy Vercel](projeto-weld-one.vercel.app)

---

#### Atividade 03 — Resumo e Relatório Técnico

**Descrição:** Formação de grupos destinados à elaboração da síntese principal do repositório, à produção de um resumo referente à aula em formato Markdown e à confecção de um relatório técnico abordando frameworks front-end (React, Angular, Vue, entre outros).

🔗 **Links da Atividade:**
- [Repositório GitHub](https://github.com/pietrosantos15/ProjetoMultiFrameworkds)


#### Atividade 04 — Pesquisa de APIs

**Descrição:** Pesquisar 10 projetos no GitHub que utilizam algum tipo de API em suas aplicações. Clonar e analisar os projetos identificando o framework utilizado, as APIs consumidas e a funcionalidade do projeto.


🔗 **Links da Atividade:**
- [Repositório GitHub](https://github.com/pietrosantos15/BuscandoAPIs)
