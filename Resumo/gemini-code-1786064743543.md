## 2. Contexto e Conceito de Front-end
* **Contextualização:** O uso de frameworks Front-end é um requisito estratégico no mercado atual para garantir a criação de aplicações web rápidas, organizadas, escaláveis e fáceis de manter[cite: 1].
* **O que é Front-end:** É a camada da aplicação com a qual o usuário interage diretamente[cite: 1]. Envolve a criação de interfaces, organização visual, experiência do usuário (UX) e a integração/comunicação com os sistemas de processamento de dados (Back-end)[cite: 1].
* **Arquitetura e Etapas:** 
  * Definição de escopo, prototipação, UX/UI e iteração[cite: 1].
  * Uso do versionamento de código e deploy[cite: 1].
  * Fundamentos com **Vanilla JS** (JavaScript puro, sem dependências externas) para manipulação de páginas e lógica da interface[cite: 1].

---

## 3. Introdução aos Frameworks Front-end
Estudo sobre como os frameworks e bibliotecas organizam a aplicação web modernamente[cite: 1]:
* **Principais Tecnologias:** React, Vue.js e Angular[cite: 1].
* **Pilares do Desenvolvimento Moderno:**
  * **Componentização:** Organização e reuso de elementos estruturais da interface[cite: 1].
  * **Gerenciamento de Estado e Dados:** Manipulação de dados na interface e integração com APIs[cite: 1].
  * **Roteamento:** Navegação entre páginas/telas em Single Page Applications (SPAs)[cite: 1].
  * **Frameworks CSS:** Estilização responsiva e ágil[cite: 1].
